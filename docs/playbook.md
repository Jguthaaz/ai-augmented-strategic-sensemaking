# Playbook de trabajo
Síntesis propia organizada con la secuencia A.G.E.N.T.; no reproduce materiales formativos.

| Fase | Trabajo | Evidencia de salida |
|---|---|---|
| Audit | Reconstruir cómo se realiza hoy el diagnóstico; identificar traspasos manuales y criterios tácitos | Mapa actual, fuentes, responsables, tiempos y pérdidas de contexto |
| Gauge | Evaluar impacto, repetibilidad, complejidad, disponibilidad de datos y riesgo | Elección de homologación y comparación como oportunidad acotada |
| Engineer | Diseñar desde la decisión que se quiere mejorar | Contratos de entrada/salida, reglas de paso, estados y prototipo |
| Navigate | Aplicar autorizaciones, separación de proyectos, revisión y manejo de excepciones | Registro de permisos, decisiones de revisión y versiones |
| Track | Comparar con una línea base y revisar efectos no deseados | Métricas, errores, esfuerzo total y aprendizajes |

## Flujo operativo propuesto
1. Acordar pregunta, segmento, periodo y definición de fuga.
2. Inventariar fuentes y registrar permisos.
3. Estructurar datos y verificar definiciones, unidades y cobertura.
4. Contrastar fuentes; conservar tanto coincidencias como contradicciones.
5. Formular hipótesis con alternativas y evidencia faltante.
6. Revisar con el consultor las ambigüedades relevantes y seleccionar preguntas.
7. Explorar hipótesis con el equipo; registrar cambios y nuevas perspectivas.
8. Priorizar según criterios explícitos, conservando desacuerdos.
9. Asignar pruebas y reabrir hipótesis si aparece evidencia que cambie su sustento.

## Criterio metodológico
Una afirmación del cliente se registra como afirmación, no como hecho. Un patrón observado no demuestra causalidad. Una aprobación se refiere a una versión concreta. Un framework organiza preguntas, pero no valida sus respuestas.
